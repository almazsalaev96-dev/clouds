# §09 Design system and UX specification ("every pixel")

## 09.1 Design principles
The interface is a pedagogical instrument. Calm removes extraneous load; speed keeps feedback inside the window where the Attempt is still in working memory; one visible next action is the visual form of "one move per Turn". Every token and component below serves one of those three. Each principle is a rule plus the test a reviewer runs; a PR that fails the test does not merge.

| ID | Principle | Rule | Test |
|---|---|---|---|
| 09-PRIN-001 | Calm by default, expressive by exception | Motion, colour and celebration budgets are spent only on rare moments; the product has exactly one celebratory animation (a paper first reaching Exam-ready). | grep the animation registry: one entry tagged `celebrate`; no confetti/particle code in the bundle. |
| 09-PRIN-002 | The source is one gesture away | Every claim about a syllabus, mark scheme, examiner report or textbook carries a citation chip that opens the exact page. | Sample 50 assistant paragraphs with syllabus claims: 50 chips; chip → highlighted page ≤400 ms p95 from cache. |
| 09-PRIN-003 | Reading is the primary activity | Body text 17 px/1.55 at ≤68 ch in chat; 18/1.6 at ≤66 ch in the reader; nothing anywhere wider than 75 ch. | Playwright measures the widest paragraph on every screen at 1280, 1600 and 2560 px. |
| 09-PRIN-004 | Mode is visible and cannot be lost | The Learn · Practise · Mark chip is always in the composer; no study toggle exists anywhere. | Five new users name the current mode within 3 s in a moderated test; no `study_mode` boolean in settings. |
| 09-PRIN-005 | One move, then the pen comes back | A Turn ends with the composer focused and its placeholder naming the next action. | 100 sampled Turns: composer focused after paint in 100%; placeholder ≠ default in ≥90%. |
| 09-PRIN-006 | Evidence on the page | A Mark highlights credited, partial and uncredited spans inside the student's own answer; a credited point without a span is a defect. | Mark eval fixture: 0 credited points without `credited_spans[]`; each span resolves to a DOM range. |
| 09-PRIN-007 | A band, not a point | Totals render as low–modal–high; a single integer total never appears without its band. | Visual regression on Mark view: band present in every fixture including points papers ("7–8 / 9"). |
| 09-PRIN-008 | Hierarchy over recency | The sidebar is Course › Unit › Syllabus point; Recent and Due are secondary groups. | Sidebar snapshot: tree first; no chat list as the primary group. |
| 09-PRIN-009 | Instant acknowledgement, honest waiting | Optimistic echo <50 ms; status text at 800 ms; "Taking longer" + Stop at 6 s; no decorative loaders. | Synthetic 3 s TTFT: three states observed at the right times in a recorded trace. |
| 09-PRIN-010 | Stability while streaming | DOM above the stream cursor is immutable; unclosed math/code is held as a skeleton. | CLS above cursor = 0 in the jank test on 20 golden streams. |
| 09-PRIN-011 | Borders first, shadows second | Surfaces are defined by 1 px hairlines; stacked soft shadows only on floating layers; no shadows on list cards. | Stylelint: `box-shadow` only via `--shadow-*` tokens; shadow-2+ forbidden on `.card-list *`. |
| 09-PRIN-012 | Grey dark mode with a ladder | Dark surfaces are a five-step grey ladder from 16% L; never `#000`; elevation = lighter surface. | Token test: no dark token with L <14%; every pair passes contrast. |
| 09-PRIN-013 | Accessibility numbers are tokens | 24 px targets, 44 pt touch, 2 px/3:1 focus, 4.5:1 text, 320 px reflow are CSS tokens and CI gates, not guidelines. | axe + custom checks green on every PR; failing check blocks merge. |
| 09-PRIN-014 | Keyboard-complete, thumb-complete | Every action has a key on desktop and sits in the bottom 40% of the screen on a phone. | Keyboard traversal script completes each screen's primary flow; mobile primary controls within the thumb zone in screenshots. |
| 09-PRIN-015 | Progress is evidence and reversible | Mastery is four states by shape with a reason; it decays and says why; no bare percentages, no streaks. | Copy corpus policy test: zero strings matching the streak/shame lexicon; no `%` in mastery components. |
| 09-PRIN-016 | Respect attention | ≤1 opt-in factual notification per day; none in Quiet Hours; never loss-framed, never a predicted grade. | Notification scheduler unit test; copy lint on notification templates. |
| 09-PRIN-017 | Math and handwriting are native | LaTeX in, KaTeX + MathML out, keypad and camera are composer states; photo → confirmed transcript before any Mark. | 200-formula render suite incl. `mhchem`; no Mark request without `transcript_confirmed=true`. |
| 09-PRIN-018 | One reading-preference set everywhere | Family, size, leading, tracking, measure are set once and honoured by chat, reader, Cards and print. | Change each preference; screenshot chat, reader, Card, print preview: all reflect it. |
| 09-PRIN-019 | Numbers are honest and tabular | Every changing number uses tabular numerals; every estimate names its basis (series, n, agreement). | Font-feature audit on timers, countdowns, marks; calibration line present on every Mark. |
| 09-PRIN-020 | Limits are visible, never sudden | Usage shows in plain numbers; slow-down replaces hard stops; exam-week grace is stated. | Simulate quota exhaustion mid-Session: no modal, no stop; factual line and cheap-tier continuation. |

Why: the praised 2025–26 redesigns (Linear, Gemini's larger type) reduced noise and raised hierarchy; the criticised ones (pulsing "thinking" backgrounds, flat recency sidebars) added motion or clutter with no task benefit (research/ux-design §0). Students' top interface complaints are walls of text and busy screens (student-voice §0.8, §9).

## 09.2 Typography tokens
**09-TYPE-001** Families. Ship exactly these, self-hosted, subset for Latin + Cyrillic + Cyrillic-ext + Greek + math symbols; no CDN fonts.

| Token | Family | Role | Notes |
|---|---|---|---|
| `--font-sans` | Inter (variable, `opsz` axis) → system-ui | UI and reading default at launch | `font-feature-settings: "cv11", "ss03"` off by default; `tnum` on numbers. Default change to a serif only after the v1 reading-fatigue A/B (JUDGING 12). |
| `--font-hyper` | Atkinson Hyperlegible Next (variable, 7 weights) | Reading-comfort option | 150+ languages; b/d remain mirrored, so it is a low-vision face, not a dyslexia cure. |
| `--font-dys` | OpenDyslexic | Reading-comfort option | Individual font effects are real (Wallace et al. 2022) — offer choice, never one "dyslexia font". |
| `--font-serif` | Literata → PT Serif → Georgia | Optional reading face | Must have true Cyrillic italics (09-I18N-004). |
| `--font-mono` | Geist Mono → JetBrains Mono → ui-monospace | Code, LaTeX source, `ecf`/annotation badges | Slashed zero on. |

| Token | Size/LH | Use | Measure |
|---|---|---|---|
| `--text-xs` | 12/1.35 | captions, chip numerals, interval hints | — |
| `--text-sm` | 13/1.4 | status lines, metadata, calibration badge, mode-chip labels | — |
| `--text-ui` | 14/1.43 | controls, sidebar rows, table cells | — |
| `--text-body` | 17/1.55 | chat Turns, Mark rationale | 68 ch (≈720 px Inter) |
| `--text-read` | 18/1.6 | reader, student answer in Mark view, Card back | 66 ch |
| `--text-focus` | 20/1.6 | reader "Focus" | 60 ch |
| `--text-lg` | 20/1.4 | Card face body | — |
| `--text-h3` | 20/1.3 · 600 | maximum heading inside a Turn | — |
| `--text-h2` | 24/1.25 · 600 | screen section titles | — |
| `--text-h1` | 30/1.2 · 600 | screen titles | — |
| `--text-display` | 36/1.1 · 600, tracking −0.02 em | landing line only | — |

Tracking: display −0.02 em; body 0; caps labels +0.06 em. Paragraph gap 0.75 em in chat, 1 em in reader; no first-line indent. Lists 4 px between items, marker inset 1.25 em. Nothing under 12 px anywhere; nothing under 11 pt on iOS.

**09-TYPE-003** Tabular numerals. `font-variant-numeric: tabular-nums` on timers, countdowns, marks, bands, due counts, intervals, thresholds and every table numeric column; numeric columns right-aligned. Acceptance: a timer counting from 09:59 to 10:00 does not shift the characters to its right.

**09-TYPE-004** Headings inside assistant content are capped at `--text-h3`; `h1`/`h2` from model markdown are demoted at render. Why: a Turn is not a landing page; students name "walls" as a top pain.

**09-TYPE-005** Weights: 400 body, 500 UI labels and modal marks, 600 headings and the bold modal number in a band. Never 300 or lighter; never 700+ except the modal mark in a band.

**09-TYPE-006** Glyph coverage. CI renders the sentence "Ә Ғ Қ Ң Ө Ұ Ү Һ І — Қазақстан, Өскемен; ёж, щука, ъ" plus "∑ ∫ ≤ ≥ ≠ → ⇌ ° µ" in every family and fails on any fallback glyph (see 09-I18N-002).

**09-TYPE-007** Text-spacing survival. Every screen survives WCAG 1.4.12 (line-height 1.5×, paragraph 2×, letter +0.12 em, word +0.16 em) and 200% font scaling without clipping or overlap. Acceptance: Playwright injects the text-spacing stylesheet; no element reports `scrollWidth > clientWidth` except tables, code and PDF pages.

## 09.3 Spacing, radii, sizes and elevation
**09-SPCE-001** Spacing is a 4 px base; only these tokens: `--space-1..16` = 4 8 12 16 20 24 32 40 48 64. Component internals may use 2 px only for hairline offsets (focus ring offset, chip padding-inline 6 px counts as 4+2). Stylelint rejects any margin/padding/gap not expressed as a token.

**09-SPCE-002** Radii: `--radius-xs` 4 (keycaps, code inline) · `-sm` 6 (rows, chips, citation chips) · `-md` 8 (buttons, inputs) · `-lg` 12 (composer, cards) · `-xl` 16 (user message block, sheets top corners) · `-2xl` 20 (large panels) · `-pill` 9999 (mode chip, intent chips, tags). Nested radii: inner = outer − padding, never larger than outer.

**09-SPCE-003** Sizes.

| `--target-min` | 24 | every pointer target (WCAG 2.5.8) |
| `--touch-min` | 44 | every target on coarse pointers |

| `--control-h-lg` | 44 | primary CTA on mobile, sheet buttons |
| `--row-h` | 32 | sidebar rows, palette rows, tree rows |
| `--chip-h` | 32 | mode chip, intent chips |
| `--cite-h` | 18 | citation chip (24 px hit area) |
| `--composer-min` | 56 | composer at rest; grows to 8 lines |
| `--topbar-h` | 48 desktop / 44 mobile | |

**09-SPCE-004** Elevation is border-first. `--ring-hairline: 0 0 0 1px oklch(0% 0 0 / .08)` (dark: `oklch(100% 0 0 / .08)`). `--shadow-1` = hairline (cards, inputs). `--shadow-2` = `0 1px 1px /.02, 0 2px 2px /.04` + hairline (popovers, hover cards, dropdown). `--shadow-3` = `0 2px 2px /.04, 0 8px 16px −4px /.04` + hairline (sheets, drawers). `--shadow-4` = `0 1px 1px /.02, 0 8px 16px −4px /.04, 0 24px 32px −8px /.06` + hairline (the rare modal). No single heavy drop; no shadow above 12% alpha; no shadows on cards inside lists or on the Turn canvas. Dark mode conveys elevation by surface step, not shadow strength.

**09-SPCE-005** Grid. Desktop ≥1280: `grid-template-columns: var(--sidebar-w) 1fr var(--panel-w)`; between 1280 and 1600 the panel shrinks first to its minimum; above 1600 surplus goes to centre margins, never to the measure. Tablet 900–1279: `1fr 420px`, sidebar overlay. Mobile <900: one column. Acceptance: resize 1280→2560; centre paragraph width stays ≤68 ch throughout.

**09-COLR-002** Mastery pip colours. State is carried by shape (empty ring · ¼ · ¾ · full disc) and colour reinforces: Unseen ring `--border`; Shaky ¼ `--warning`; Secure ¾ `--success`; Exam-ready full `--success` with a 1 px `--text` outline. A decaying Secure pip (retrievability <0.7) renders Shaky by shape and colour together. Acceptance: pips remain distinguishable in a greyscale screenshot.

**09-COLR-003** Heatmap: five tones of one hue — `oklch(93% .03 250)`, `86% .07`, `76% .11`, `64% .14`, `52% .16` (dark: `24% .03 250` → `72% .13`) — mapped to learning events per day; empty day = `--bg-el`. Never red; never a streak count.

**09-COLR-004** Span marking colours: credited = 2 px underline `--accent` + `--accent-subtle` wash; partial = 2 px dotted `--accent`; uncredited attempt = 2 px dotted `--warning`; ECF = `--accent` underline with `ecf` mono badge. **09-COLR-005** Contrast+ variant: text 12 → `10% / 98%`, borders +1 step, `--text-muted` → `36% / 80%`, all alphas ×1.3, hairlines 1.5 px. Ships with both themes at launch.

**09-COLR-006** CI runs an APCA/WCAG matrix over every text-role × surface-role pair in light, dark and Contrast+; any pair below 4.5:1 (3:1 for ≥24 px/19 px bold and for UI borders/focus rings) fails the build.

## 09.5 Motion
**09-MOTN-001** Durations and easings are tokens; a lint forbids any `transition`/`animation` that does not use them.

```css
--dur-press: 120ms;   /* :active scale .97, chip select */
--dur-tooltip: 150ms; /* tooltips, selection popover, hover card (120ms allowed for cite card) */
--dur-fast: 180ms;    /* dropdown, popover, toast in */
--dur-base: 220ms;    /* delta fade-in, card expand, tab switch */
--dur-page: 260ms;    /* route transitions (mobile push) */
--dur-drawer: 320ms;  /* sheets, sidebar overlay, right pane open */
--dur-celebrate: 400ms; /* the one two-tone ring fade */
--stagger: 40ms;      /* max 6 items staggered */
--ease-out: cubic-bezier(.23,1,.32,1);
--ease-in-out: cubic-bezier(.77,0,.175,1);
--ease-drawer: cubic-bezier(.32,.72,0,1);
--spring-gesture: { type: spring, duration: .5, bounce: .15 }  /* drag-to-dismiss only */
```

**09-MOTN-002** Rules: animate only `transform`, `opacity` and `clip-path`; entrances start at scale .96 (never 0) from `transform-origin` at the trigger; exits run ~20% faster than entrances; elements that move together share duration and easing; hover effects only under `(hover:hover) and (pointer:fine)`; no transition exceeds 320 ms except the single 400 ms celebration.

**09-MOTN-003** Zero-animation actions (an animation here is a defect): Send/Stop swap, message append, command palette open/close, any keyboard-initiated action, tab switch in the right pane, mode-chip change, pip state change, flashcard button press, timer ticks, sidebar row selection.

**09-MOTN-004** Forbidden: `ease-in` on UI, `scale(0)`, bounce or overshoot outside drag-to-dismiss, pulsing or gradient "thinking" backgrounds, typing-cursor blink faster than 1 Hz, shimmer >1.6 s loop, parallax, auto-playing loops, confetti, particles, mascots, loss animations, layout-affecting animations (height/width/margin).

**09-MOTN-005** Reduced motion (`prefers-reduced-motion: reduce`, or forced in Settings): all transforms removed; opacity/colour fades only at ≤160 ms; skeleton shimmer off; sheets appear in place; flashcard flip becomes a 150 ms crossfade; the celebration becomes a 400 ms colour change. Acceptance: Playwright run with reduced motion records no element whose bounding box changes during any transition.

**09-MOTN-006** Haptics (mobile): light impact on card flip and Got it; selection tick on keypad keys; none on Again, on Marks or on any tutor error — the product never punishes.

## 09.6 Iconography
**09-ICON-001** One outline family (Lucide), 24 px grid, 2 px stroke, 1 px optical padding; 16 and 20 px optical variants for dense rows; icon colour = the text colour of its row; never two families on one surface; no filled variants except the Send button glyph and the active mode segment.

**09-ICON-002** Marking glyphs are typographic, never emoji: ✓ (credited), × (uncredited), Ø (nothing creditable), BOD, ECF, NC, CON, RE, GA, I rendered as 16 px `--font-mono` 600 margin badges; ✓ uses `--success`, × `--danger`, the rest `--text-muted`. Every glyph has a tooltip and `aria-label` with the full phrase ("Error carried forward").

**09-ICON-003** Trust badges are text badges (Syllabus · Endorsed textbook · Mark scheme · Examiner report · Revision notes · Your notes) at `--text-xs` 500 caps, `--bg-el` fill, radius 4, never coloured by rank. Provenance chips (OWN · LICENSED · USER) appear only in Library and teacher views.

**09-ICON-004** Emoji are banned from system copy, icons and model output (lint, 09-COPY-006). The only permitted symbols are typographic (· — → ✓ × ▸ ↓ ¼ ¾ ∑).

Hard/Easy behind a setting. Provenance line on every card. |

| **EmptyState** | one sentence + one action; no illustration larger than 64 px, no mascot | per screen in §10. |

Acceptance for the whole inventory: Storybook shows every state; visual regression on light/dark/Contrast+ at 320, 768, 1280 and 1600 px; every interactive element ≥24 px (44 on touch).

## 09.8 The streaming contract
Every streamed surface (Turn, Mark, debrief, generated Item) obeys this contract; it is tested in CI against 20 recorded golden streams with synthetic TTFT of 0.3, 1.5, 3 and 8 s.

| ID | Requirement | Acceptance |
|---|---|---|
| 09-STRM-001 | Optimistic echo: the user message appears, composer clears, scroll pins, and a three-dot indicator occupies the assistant slot within 50 ms of Send. | Performance trace: paint ≤50 ms after keydown. |
| 09-STRM-002 | At 800 ms without a first token the dots become one 13 px muted status line drawn from the route ("Reading the 9609 P2 mark scheme…", "Checking the working with SymPy…"); text, never a spinner or pulsing background. | Synthetic 1.5 s TTFT shows the line at 800±50 ms. |
| 09-STRM-003 | At 6 s: "Taking longer than usual" plus Stop; at 20 s the InlineError offers "Retry with Think" and "Copy my message". | Synthetic 8 s and 25 s traces. |
| 09-STRM-004 | Tokens are buffered and painted per frame at ≤90 characters per 16 ms; bursts are paced. | No frame paints >90 new characters. |
| 09-STRM-005 | DOM above the stream cursor is immutable: earlier paragraphs, lists and tables are never re-laid out; markdown is committed block by block. | CLS measured above the cursor = 0 on all golden streams. |
| 09-STRM-006 | Unclosed `$$…`, ``` fences, tables and AOCards hold a skeleton of the expected height until closed; inline `$…$` renders only when closed. | No visible raw LaTeX or fence markers at any frame. |
| 09-STRM-007 | Auto-scroll stops after 120 px of user scroll; a "↓ New" pill (32 h, `--bg-el`, hairline) appears bottom-centre; tapping it re-pins. | Scroll up 150 px during a stream: no yank; pill visible. |
| 09-STRM-008 | Stop replaces Send in place (same position, same 36 px); the partial Turn stays, tagged "Stopped"; no animation on the swap. | Screenshot diff of the button box before/after. |
| 09-STRM-009 | Thinking renders as a collapsed non-animated "Thought for 6 s ▸" row; expanding shows a summary, never a live token stream by default. | Story state. |
| 09-STRM-010 | The lint (§04) runs before paint; a rejected draft regenerates without any visible artefact; the template fallback paints as a normal Turn. | Golden stream with an injected "Great question!" shows no flash of the rejected text. |
| 09-STRM-011 | Mark streaming order: MarkHeader → one AOCard each within 8 s → BandTotal + CalibrationBadge → next-mark advice; spans light in the answer as their card commits. | Recorded Mark stream: header ≤2 s, each card ≤8 s, full ≤45 s p95. |
| 09-STRM-012 | Screen readers: the completed Turn is announced once via `role="log" aria-live="polite"`; never per token. Status lines are announced once each. | NVDA/VoiceOver script. |
| 09-STRM-013 | Resumable: on reconnect the client resumes the SSE stream from the last part id; the partial Turn is never duplicated. | Kill the network at 40% of a golden stream; final DOM equals the uninterrupted golden. |

## 09.9 Reading-comfort settings
**09-READ-001** One preference object, stored per user (synced) and applied by CSS custom properties on `:root`, honoured by chat, Mark view, reader, Cards, artifacts and print:

```json
{ "family": "inter|hyperlegible|opendyslexic|serif|system",
  "size_px": 17, "leading": "1.4|1.55|1.7", "tracking_em": "0|0.05|0.12",
  "measure": "narrow|medium|wide", "warm_bg": false, "capitalise_words": false,
  "theme": "system|light|dark", "contrast_plus": false, "reduce_motion": "system|on",
  "reduce_transparency": false, "read_aloud_rate": 1.0 }
```

**09-READ-002** Controls (Settings › Reading comfort, also reachable from the reader header and ⌘K "Reading comfort"): family radio with live specimen in each face; size stepper 14–24 px (chat and reader scale together; UI text does not scale below 14); leading and tracking three-segment controls; measure narrow 56 ch / medium 68 ch / wide 75 ch; **Reading-comfort preset** one tap = 18 px / 1.7 / +0.05 em / 60 ch / warm background `oklch(96% .012 85)`; "Capitalise Each Word" toggle (applies to assistant text only, never to quotes or code). Every control has a one-line consequence beneath it.

**09-READ-003** Read aloud: every Turn, Card and reader page has a Read-aloud action (system TTS; 0.8–1.5× rate); math is spoken via MathML + lazily loaded SRE ("x squared plus 3 x"); code is read with punctuation. Acceptance: read-aloud of a Turn with an inline fraction produces the SRE string, not "dollar frac".

**09-READ-004** Size and family changes apply without reload and without layout shift outside the text itself; measure is enforced by `max-width: var(--measure)` on the text column, not by the pane width. Why: dyslexic and ADHD students name busy screens and dual-column text as the reason they cover half the browser (student-voice §9); a switcher beats a single "dyslexia font" (Wallace et al. 2022).

## 09.11 Microcopy voice and the copy lint
**09-COPY-001** Voice: an examiner who is on your side. Short, specific, declarative; examiner vocabulary explained in plain words on first use; the mark scheme's own terms ("developed", "application", "judgement") used exactly. No exclamation marks, no emoji, no "Great question", no therapy-speak, no guilt, no urgency framing. Numbers carry their basis. The system never speaks about its own feelings and never apologises more than once.

**09-COPY-002** Canonical strings (do / don't). The "Do" column is the shipped string; the "Don't" column is the lint counter-example used as a regression fixture.

| # | Situation | Do | Don't |
|---|---|---|---|
| 1 | Effort Gate | "Have a go first — a plan or the first line is enough." | "Let's try it together! What do you think the answer might be? 😊" |
| 2 | Just the answer, before attempt | "After one attempt." | "Sorry, I can't give you the answer yet!" |
| 3 | Seen-solution tag | "Seen solution · retest Thursday." | "Solution revealed — don't forget to review!" |
| 4 | Command-word check | "Evaluate — a judgement is required. None found, so AO4 is capped at Level 2." | "Great analysis! Just remember to add a conclusion for top marks!" |
| 5 | Uncredited span reason | "Assertion without a link in the chain — L1, not L2." | "This point could be developed a bit more." |
| 6 | ER quote | "Examiners' report, m25: 'simply repeating the business name will not count as application.'" | "Examiners hate it when you do this!" |
| 7 | Calibration badge | "Calibrated on 9609 P2 · agreement 0.82 · 312 scripts." | "AI-powered accurate grading." |
| 8 | Below-gate Mark | "Practice estimate — not yet calibrated for this paper. Feedback and evidence shown; no mark." | "Estimated score: 14/20 (may be inaccurate)." |
| 9 | Notification | "18 cards due · about 6 minutes." | "Don't lose your progress! Review now 🔥" |
| 10 | Exam-week grace | "Exam week: marking limits are off until Friday." | "Good news!! Unlimited marking unlocked!" |
| 11 | Quote unverifiable | "I can't confirm that quote from the set text, so I won't use it." | "Here's a quote that might be from the text." |
| 12 | Weekly card | "4 of 4 sessions. 3.2 Motivation moved to ¾. Paper 2 readiness unchanged: no timed practice this week." | "Amazing week! You're on fire! Keep the streak alive!" |

**09-COPY-003** Copy lint runs on the string catalogue (CI) and on model output before paint (§04/§08). Rules, each a regex or classifier with a fixture: (a) exclamation marks: 0 allowed; (b) emoji and pictographic symbols: 0; (c) person-praise lexicon ("great", "amazing", "brilliant", "well done", "good job", "you're a natural", "genius") outside a quoted span: block; (d) guilt/loss lexicon ("don't lose", "streak", "missed", "you failed to", "falling behind", "last chance"): block; (e) urgency ("now!", "hurry", "only today"): block; (f) therapy-speak ("take a breath", "it's okay to feel", "I hear you"): block in tutor and system copy, allowed once in the distress script; (g) "Great question", "Absolutely", "Certainly", "As an AI": block; (h) hedged marks ("might be", "roughly") in BandTotal: block — the band is the hedge; (i) unlabelled estimates: any grade or mark string must carry a basis token (series, n, or "practice estimate"); (j) vendor names in headlines: block (chip only). Thresholds: praise rate on the weekly 1% Turn audit <5%; catalogue violations = 0.

**09-COPY-004** Placeholders name the action: after a Turn the composer placeholder is the hand-back ("Try the next line", "Name the stakeholder first", "Paste your rewrite"); default placeholder "Ask, paste an answer, or /practise".

**09-COPY-005** Errors state cause and remedy in ≤2 sentences with no apology theatre: "The marker timed out. Retry with Think, or copy your answer." Never "Oops".

**09-COPY-006** Localised strings follow the same lint per language; Russian and Kazakh catalogues are reviewed by a native examiner-teacher for register (formal "вы", no diminutives).
